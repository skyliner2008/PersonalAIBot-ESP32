# 16 — หน้าปัดรถ (รถยนต์ + มอเตอร์ไซค์)

หน้าจอหน้าปัดแบบรถแข่ง: **บาร์รอบเครื่อง + shift light**, ความเร็วตัวใหญ่, เกียร์, และช่องอุณหภูมิเครื่อง / แบตเตอรี่ / อากาศเข้า (หรือคันเร่ง)

## รูปแบบหน้าปัด 3 แบบ (T077)

### ⚠️ Bluetooth: บอร์ดนี้ (ESP32-S3) มีแค่ **Bluetooth LE**
ELM327 ราคาถูกส่วนใหญ่เป็น **Bluetooth Classic (SPP)** → **ใช้ไม่ได้** · ต้องเป็นรุ่น **BLE** เช่น Vgate iCar Pro BLE, Veepeak BLE, Konnwei BLE, OBDLink CX
(สเปก "Bluetooth 4.2 BR/EDR + LE" เป็นของ ESP32 รุ่นแรก เช่นบอร์ด CYD — ไม่ใช่ ES3C28P: framework ระบุว่า S3 ไม่มี BR/EDR)
- **รีสตาร์ท 1 ครั้งหลังเลือก `obd_ble`**: Arduino คืนหน่วยความจำของ BLE (~36 KB RAM ภายใน) ตอนบูตถ้าไม่มีใครใช้ — `bleInUse()` (`VehicleLink.cpp`)
  อ่าน NVS ตอนบูตแล้วเก็บไว้เฉพาะเมื่อแหล่งข้อมูลเป็น `obd_ble` · แหล่งอื่น/ไม่ใช้หน้าปัด = RAM เท่าเดิม
- ค้นหา 6 วิ เลือกตัวที่ชื่อ/บริการดูเป็น OBD (`OBD`, `ELM`, `VLINK`, `VEEPEAK`, `KONNWEI`, `VGATE`, บริการ FFF0/FFE0/18F0) ที่สัญญาณแรงสุด → จำ address ไว้ต่อตรงครั้งหน้า
  (เมนู "ค้นหา adapter Bluetooth ใหม่" / `dash ble forget` ล้างที่จำ) · log `[Vehicle]   AA:BB:..  ชื่อ  rssi  <- OBD?` แสดงทุกตัวที่เจอ
- ช่องข้อมูล: คู่ที่รู้จัก (FFF0: FFF1/FFF2, FFE0: FFE1, 18F0: 2AF0/2AF1, Nordic UART, E7810A71) ไม่งั้นใช้ notify + write คู่แรกที่เจอ
- RAM ภายในเหลือ < 40 KB ตอนจะเปิด Bluetooth → ไม่เปิด (สถานะ `BT NO RAM`) — ปิดคำปลุกคำหนึ่ง (`set wakeword hiesp`) ช่วยได้
- หา adapter ไม่เจอ (ดับเครื่อง/ถอดออก) → สแกนใหม่ทุก 15 วิ: การสแกน BLE ใช้คลื่นร่วมกับ Wi-Fi (เสียง AI อาจสะดุดช่วงสแกน)

### Honda K-Line (มอเตอร์ไซค์หัวฉีด PGM-FI: Wave 110i / 125i, Click, PCX, MSX ...)
- สาย K-Line ไฟ 12V → **ต้องมีบอร์ดแปลง** (L9637D / MC33290 / โมดูล "K-Line to TTL") — **ห้ามต่อ K-Line เข้าขาบอร์ดตรงๆ**
- ต่อ: K ↔ K-Line ของปลั๊กวิเคราะห์ (DLC), VS ↔ 12V รถ, GND ↔ GND รถ + GND บอร์ด, **TX ของบอร์ด (GPIO 43) → TX/IN ของโมดูล**, **RX/OUT ของโมดูล → GPIO 44**
  · ขา GPIO รับได้ **3.3V เท่านั้น**: โมดูลที่ดึง RX ขึ้น 5V ต้องลดระดับ (หรือใช้รุ่น 3.3V) · เฟิร์มแวร์เปิด pull-up ภายในที่ GPIO 44 ให้ (L9637D เป็น open collector)
  · ขาช่อง UART บนบอร์ด **สันนิษฐาน** ว่าเป็น GPIO 43/44 (wiki 15) — วัดยืนยันก่อน · ตอนบูต ROM พิมพ์ข้อความออก TX: ECU ไม่สนใจเพราะยังไม่ได้ปลุก
- โปรโตคอล: 10400 baud · ปลุก K-Line low 70 ms / high 130 ms → `FE 04 FF FF` → `72 05 00 F0 99` (ตอบ `02 04 00 FA`) → ขอตาราง `72 05 71 <table> <cs>` ~15 ครั้ง/วิ
  · checksum = ผลรวมทุกไบต์ของเฟรม = 0 (mod 256) · ตัดเสียงสะท้อน (echo) ที่โมดูลส่งกลับให้เอง
- **ตำแหน่งข้อมูลในตาราง (layout) แต่ละรุ่นไม่เหมือนกัน** — ค่าเริ่มต้น: ตาราง 0x11, รอบ = ไบต์ 0–1, อุณหภูมิ 5, อากาศเข้า 7, MAP 9, แบต 12 (÷10), ความเร็ว 13
  **ยังไม่ได้ทดสอบกับรถจริง**: ดูไบต์ดิบด้วย `dash kdump` แล้วแก้ใน `agent/vehicle.json`:
  `{"kline": {"table": 17, "rpm": 0, "coolant": 5, "intake": 7, "map": 9, "battery": 12, "speed": 13, "throttle": -1}}` (-1 = ไม่อ่าน)
- Wave รุ่นเรือนไมล์สายกล ECU ไม่รู้ความเร็ว → ความเร็วเป็น `--` · มอเตอร์ไซค์ไม่แสดงเกียร์ (ค่าเริ่มต้นไม่ประมาณ)

### OBD-II ผ่าน ELM327 (BLE หรือสาย)
`ATZ` → `ATE0` `ATL0` `ATS0` `ATH0` `ATAT1` `ATSP0` → `0100` (รถบอก PID ที่รองรับ) → วนอ่าน `010C` (รอบ, ทุกคำสั่งเว้นคำสั่ง) `010D` `0105` `010F` `0111` `010B`
เฉพาะที่รองรับ + `ATRV` (แบต) ทุก 2 วิ · ไม่ตอบ 3 ครั้ง = เริ่มใหม่ (`NO ADAPTER`) · ค้นหาไม่เจอ ECU (`UNABLE TO CONNECT`, ดับเครื่อง) = `NO ECU` แล้วลองใหม่ทุก 4 วิ
· รถยนต์เกือบทุกคันที่ขายในไทยหลังปี 2008 มี OBD-II · มอเตอร์ไซค์ส่วนใหญ่ **ไม่มี** OBD-II มาตรฐาน → ใช้ K-Line

## เกียร์ / ค่าเตือน
- เกียร์: ใช้ค่าจากแหล่งข้อมูลถ้ามี (`gear=` ใน serial) ไม่งั้น **ประมาณจากรอบ ÷ ความเร็ว** เทียบอัตราทดเกียร์ (ค่าเริ่มต้นรถเก๋ง 5 เกียร์ 1.5 ลิตร, ล้อ 195/65R15)
  ไม่ตรงเกียร์ไหน (คลัตช์ลื่น/ปลดเกียร์) = `-` · จอดนิ่งรอบเดินเบา = `N` · มอเตอร์ไซค์ปิดไว้
- เตือน (รถยนต์ / มอเตอร์ไซค์): อุณหภูมิเครื่อง ≥ 105/120°C เหลือง, ≥ 112/135°C แดง · < 60/50°C ฟ้า · แบต < 11.8/12.0 V ขณะเครื่องติด หรือ > 15.2/15.0 V
- AI พูดเตือนเมื่อเครื่องร้อนวิกฤต / แบตต่ำขณะเครื่องติด / แบตสูงเกิน ค้างเกิน 5 วิ (ไม่เตือนเพราะค่ากระตุกครั้งเดียว) — ข้อมูลจำลองบอกว่า "(ข้อมูลจำลอง)"

## AI tool `vehicle`
ประกาศ **เฉพาะเมื่อเลือกแหล่งข้อมูลแล้ว** (บอร์ดที่ไม่ใช้รถไม่เสีย token: +370 bytes เหมือน tool `device`) · เปิด/ปิดแหล่งข้อมูล = session ใหม่หลังคำตอบปัจจุบัน
- `action`: `status` (ค่าทั้งหมด + คำเตือน), `open` / `close` (หน้าปัด), `set_source` + `source`
- ค่าที่ตอบเฉพาะที่สดอยู่: `rpm`, `speed_kmh`, `coolant_c`, `intake_c`, `battery_v`, `throttle_pct`, `map_kpa`, `gear` / `gear_estimated` + `warnings`
  · จำลอง = `simulated: true` (AI ไม่เข้าใจผิดว่าเป็นรถจริง)
