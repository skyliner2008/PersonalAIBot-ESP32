**Waveshare ESP32-S3-Touch-LCD-1.54** — ESP32-S3R8 rev v0.2 (PSRAM 8 MB Octal ในชิป) + flash 16 MB (XMC), จอ IPS 1.54" **240×240 ST7789**
(SPI), ทัช **CST816S**, ลำโพงผ่าน **ES8311**, ไมค์ 2 ตัวผ่าน ADC **ES7210**, IMU 6 แกน **QMI8658**, ช่อง microSD, แบตพร้อมวงจรล็อกไฟ,
ปุ่ม 3 ปุ่ม (BOOT/VOL−, VOL+, PWR) · มาจากโรงงานพร้อมเฟิร์มแวร์ XiaoZhi 2.0.5

**ที่มา:** ผู้ใช้ซื้อบอร์ดนี้มา (2026-11-20) — สแกนด้วย Flasher (T227–T229) แล้วขอเฟิร์มแวร์ที่**เปลี่ยนดวงตาเป็นวงคลื่นเสียง เลือกได้ 5 แบบ** และใช้ IMU
→ build แยก `pio run -e ws154` (ซอร์สเดียวกับ ES3C28P) · release: `-factory-ws154.bin` / `-app-ws154.bin` · `config` "chip" = `ws154`

**สำรองเฟิร์มแวร์เดิม:** ทั้ง flash 16 MB (XiaoZhi 2.0.5) อยู่ที่ `Documents\ESP32-AI-Flasher\backups\waveshare-s3-lcd-1.54-xiaozhi-2.0.5-full16MB.bin`
(ย้อนกลับ: `esptool --chip esp32s3 write_flash 0 <ไฟล์>`)

> วาดขนาดจริง 1:1 เต็มจอ (ไม่ย่อ 3:4 แล้ว, ตัวหนังสือใหญ่ขึ้น 33 %) · **หน้าตั้งค่า = ไอคอนกลมใหญ่ 2×2 + ชื่อใต้ไอคอน** ปัดเปลี่ยนหน้า (จุดบอกหน้า) · **รายการ =
> แถวการ์ดมนสองบรรทัด** (ชื่อ 28 px / ค่า 24 px สี) สูง 62 px · หัวข้อกลางจอ · หน้าการแจ้งเตือนเป็นตารางไอคอน + ตัวเลขจำนวนบนมุม · เครื่องเล่นวิทยุ / คีย์บอร์ด /
> การ์ดข้อมูลจัดตามความกว้าง 240 (`cardlayout` ใน CardScreen.cpp) · **นาฬิกาพักจอ 7 ธีมเขียนใหม่เป็นหน้าปัดนาฬิกา 240×240** (วงแหวนวินาที / อนาล็อก เต็มจอ,
> ตัวเลขใหญ่ชั่วโมงบน-นาทีล่าง ฯลฯ) · ข้อความด้านล่างของหัวข้อนี้ (ย่อ 3:4) เป็นแบบเดิม

- **หน้าอื่น** (เมนู, การ์ด, นาฬิกาพักจอ, วิทยุ …) ย่อทั้งจอ **3:4 → 240×180** แถบดำบน-ล่าง 30 px · ย่อแบบเฉลี่ยพื้นที่ (ทุก 4 พิกเซล → 3 ถ่วง 3:1 / 2:2 / 1:3)
  ตัวหนังสือไทยไม่ขาด
- **หมุนภาพ 4 ทิศในซอฟต์แวร์** (`UiManager::setTurn`, ตาม IMU) — ทัชใช้สูตรกลับของสูตรเดียวกัน จึงตรงเสมอ ไม่ต้องปรับเทียบ (ข้ามหน้าปรับเทียบทัชตอนบูตครั้งแรก)
- ภาพหน้าจอ (`screenshot`, Studio, แอปมือถือ) = ภาพ 240×240 ที่จอแสดงจริง
- หน้าหลักบนจอเล็ก (ผู้ใช้ขอ): **วงคลื่นเสียงเกือบเต็มจอ (scale 1.3, กลางจอเสมอ) เป็นเลเยอร์ล่าง** ไอคอนและข้อความเป็นเลเยอร์บน
  (`aa::Icon` เก็บค่าความทึบต่อพิกเซลแล้วผสมกับภาพข้างใต้ — บอร์ดอื่นยังวางทึบบนพื้นดำ)
- **ไอคอนซ่อนอยู่** — แตะจอ 1 ครั้ง = แสดง**แท็บโค้งเข้ามุมทั้ง 4** (แก้วมืดโปร่งแสง + ขอบโค้งสีฟ้า) 5 วินาทีแล้วหายเอง: ซ้ายบน **Wi-Fi** (แตะ = หน้า Wi-Fi) ·
  ขวาบน **ตั้งค่า** · ซ้ายล่าง **แบต** (แตะ = ป้าย "แบต 85% • กำลังชาร์จ" / "ไฟจาก USB") · ขวาล่าง **กระดิ่ง** (การแจ้งเตือน) · ตอนไอคอนขึ้นอยู่ แตะกลางจอ =
  แตะปกติ (หยุดพูด / ปลุก / คุย) · ยังไม่ได้ตั้งค่า (Wi-Fi / API key) = แสดงค้างไว้ให้หาเฟืองเจอ · ไม่มีเวลา / ปุ่มไมค์ / ปุ่มเพลง / ปุ่มหน้าปัดบนหน้านี้
- **ปัดจอซ้าย / ขวา** = เปิดเครื่องเล่นวิทยุ / MP3 · **ไมค์ปิด** = วงกลายเป็นสีเทาหม่น (แทนไอคอนไมค์)
- **เครื่องเล่นเพลงแบบ smartwatch (T231, `src/ui/RadioWatch.cpp`)** — ผู้ใช้ขอ "ออกแบบ UI เครื่องเล่นเพลงใหม่ ธีม Smartwatch" · พื้นดำ สีไล่ฟ้า→ม่วง→ชมพูแบบหน้าหลัก
  - **หน้าเล่น:** แถวบน ‹ กลับ · เวลา · ⏻ ปิดวิทยุ · แถวสอง ☰ รายการ · ปุ่มสลับ [วิทยุ | MP3] (วิทยุฟ้า / MP3 ชมพู) · ปุ่ม AI (สีตามสถานะ: ฟัง ฟ้า / คิด เหลือง / พูด ชมพู)
    · ชื่อสถานี / เพลง + บรรทัดสอง (ศิลปิน · เพลง 3/42 / สถานะ / "AI กำลังฟัง...") — แตะ = คุยกับ AI, กดค้าง = session ใหม่
    · **ปุ่มเล่นกลมกลางจอในวงแหวน:** วงในคือ**ความคืบหน้าของเพลง** (MP3 — `RadioPlayer::fileProgress()` ตามไบต์หลัง ID3) · ขีด 40 ขีดรอบนอก**เต้นตามระดับเสียง**
      ซ้ายฟ้า ขวาชมพู (หยุด = ขีดสั้นสีจาง) · วิทยุกำลังเชื่อมต่อ = วงหมุน · ⏮ / ⏭ วงกลมสองข้าง
    · **เสียง:** − / + (ทีละ 10 %) และ**แถบลากได้** (แตะหรือลากตามแถบ ทีละ 5 % — บันทึกตอนยกนิ้ว เพราะการบันทึกแต่ละครั้งเขียน NVS)
  - **หน้ารายการ:** ปัดขึ้น หรือแตะ ☰ — แถวการ์ดมนสองบรรทัด (ชื่อ / ประเภท หรือโฟลเดอร์) ลากเลื่อน + เหวี่ยง, แถบเลื่อนขอบขวา, แถวปัจจุบันสีม่วงเข้ม + แถบสีซ้าย
    + แท่งระดับเสียง 3 แท่งตอนเล่น · แตะแถว = เล่น + กลับหน้าเล่น · ‹ หรือปัดขวา = กลับ
  - **เขย่า / สะบัดบอร์ดไปทางซ้าย / ขวา = เพลง (สถานี) ก่อนหน้า / ถัดไป** (ผู้ใช้ขอ) — ชื่อเพลงใหม่เลื่อนเข้ามาจากทางนั้น + ปุ่ม ⏮ / ⏭ สว่างแวบหนึ่ง
    · ดูที่ "สะบัด" ใน IMU ด้านล่าง · console `ui flick 1` / `ui flick -1` = ทางเดียวกันโดยไม่ต้องเขย่า
  - ปัดขวาจากขอบซ้ายของหน้าเล่น = กลับหน้าหลัก (เพลงยังเล่นต่อ) · บอร์ดจอ 320×240 ยังใช้หน้าเดิม (`RadioScreen.cpp`, การกระทำของปุ่มใช้ฟังก์ชันร่วมกัน)
- **ไม่มีซับไตเติลบทสนทนา** (ผู้ใช้ขอ) — ไม่ขึ้นคำพูดของเราและของ AI · ยังขึ้น**ข้อความของบอร์ดเอง** (ยังไม่ได้ตั้งค่า, ผิดพลาด, คำแนะนำ) 3 บรรทัดตัว 24 px ทับวง
  พร้อมแถบมืดโปร่งแสงหลังแต่ละบรรทัด + เงาตัวอักษร · กล่องตัวเลขลอย (T226) ยังขึ้น

**ความเร็ว (วัดด้วย console `uistat`):** หน้าหลัก 13–17 fps (วาด 14–25 ms, ส่งภาพ 24 ms ที่ SPI 40 MHz ผ่าน DMA สลับ 2 แถบ 12 แถว), เมนู 11 fps ·
เส้นวงคลื่นวาดด้วย `band()` ของเราเอง (เร็วกว่า `drawWideLine` ~4 เท่า) · UI task พักครึ่งหนึ่งของเวลาเฟรม ให้ console / Flasher ได้ทำงาน ·
**SPI 80 MHz ใช้ไม่ได้** (สีเพี้ยนบนจอจริง) · init จอใช้ค่าโรงงาน (SLPOUT / **GAMSET 2.5** / NORON / DISPON) ไม่ใช้ตาราง gamma ของ LovyanGFX ·
`rgb_order = true` = MADCTL bit BGR = 0 (= `LCD_RGB_ELEMENT_ORDER_RGB` ของ Waveshare / XiaoZhi — ตั้งผิดแล้วแดง↔น้ำเงินสลับ: ฟ้ากลายเป็นเหลือง)

  · ปุ่ม PWR กดสั้นยังเปิด/ปิดไมค์ได้เหมือนเดิม · แตะที่อื่นยังเปิดแท็บ 4 มุมตามเดิม
- **รอบวง:** แสงแตกเป็นเส้น 48 เส้นยาวไม่เท่ากันกะพริบ สว่างใกล้วง จางที่ปลาย + อนุภาคลอยออก (ทุกเส้นที่ 2) — ตอนเงียบยาว 10–25 px,
  **ตอนพูดพุ่งกระจาย ~60–80 px (ปลายห่างกลางจอ ~100 px ≈ 80 % ของจอ)** ฝั่งที่พูดยาวสุด อีกฝั่งก็ขยายตาม (ผู้ใช้: "ยาว เด่นขึ้น พุ่งกระจาย")
- **พื้นหลัง nebula** (ผู้ใช้: "ไม่เอาดำสนิท"): สร้างครั้งเดียวตอนวาดเฟรมแรก (value noise + domain warp, ~2.4 s, PSRAM 115 KB) — เมฆฟ้าอมเขียวซ้าย /
  ม่วงเข้มกลาง / ชมพูม่วงขวา หรี่ไว้ให้คลื่นเด่น + ดาวนิ่ง 150 ดวง · ทุกเฟรม memcpy ลง canvas + ดาวกะพริบ 26 ดวง
- **คลื่น:** เส้นบาง 7 เส้นเป็นริบบิ้นวิ่งออกจากกลางจอไปขอบ ซ้ายสีฟ้า (cyan) → กลางม่วง → ขวาชมพู (magenta) — สีตายตัวตามรูป ไม่ใช้สีดวงตาแล้ว
  · **สีอิ่มเต็มที่** (ผู้ใช้: "จืดกว่าในรูป") เส้นสว่าง ≥ 0.8 หนาขึ้น
  · **ไหลออกจากกลางอย่างเดียว** (ผู้ใช้: "คลื่นออกแล้ววิ่งกลับเข้ากลาง"): ทุกส่วนของคลื่นเป็นฟังก์ชันของ (k·d − เฟส) อย่างเดียว ·
    ความเร็วสูงสุด ~4.5 rad/s (จอวาด ~12 เฟรม/วิ — เร็วกว่านี้ตาเห็นคลื่นวิ่งถอยหลังแบบล้อรถในวิดีโอ)
  · **ไม่มีเสียง = ไหลช้าๆ** (0.45 rad/s) — แต่ละฝั่ง / แสงรอบวง / อนุภาค มีนาฬิกาเฟสของตัวเองที่เร่งตามเสียงเท่านั้น
- **ฝั่งไหนพูด ฝั่งนั้นขยับ:** **คนพูด (ไมค์ ตอนฟัง) → ฝั่งซ้าย**เป็นคลื่นสูง + เส้นแสงฝั่งซ้ายยาว · **AI พูด (เสียง AI) → ฝั่งขวา** · อีกฝั่งหายใจเบาๆ
  (`WaveOrb::setLevels(user, ai)`)
- **สถานะ:** ว่าง = หายใจช้าๆ · คิด = ดาวหางวิ่งรอบวง + โทนม่วง · เชื่อมต่อ = ขีดหมุน + หรี่ · หลับ = มืด + "z" ลอย · ผิดพลาด = แดง · แตะ / เขย่า = เด้ง
- **เวลาวาด** (console `uistat`, บรรทัด ORB): เงียบ ~17.5 ms · **ตอน AI พูด ~41 ms (~8 เฟรม/วิ)** — เส้นยาว/คลื่นสูงวาดพิกเซลมากขึ้น และงานเสียง /
  Wi-Fi แย่ง CPU (เวลาส่งภาพขึ้นจอเองก็ช้าลงจาก 24 → 41 ms ตอนพูด) · 72 เส้นแสงยาวใช้ 33 ms → ลดเหลือ 48 เส้น, คลื่น 7 → 6 เส้น

## IMU QMI8658 (`src/system/Qmi8658.h` + `src/util/Motion.h`, host tests `test_motion.cpp`)

อ่านทุก 20 ms ใน UI task (±4 g, ±512 dps):
- **หมุนจอตามท่าวาง** (เมนู "หมุนจอตามท่าวาง (IMU)", `set autorotate 0/1`, ค่าเริ่มต้นเปิด) — ขอบไหนชี้ลงค้าง 0.7 วิ → หมุนไปทางนั้น · วางราบ / เอียงมุม = คงเดิม ·
  ปิด = ใช้ "หมุนจอ 180°" เดิม
- **เขย่า** (แกว่ง > 0.9 g สลับข้าง 4 ครั้งใน 1.2 วิ) = เหมือนแตะหน้าจอ (ปลุก / หยุดพูด / เริ่มฟัง) + วงเด้ง
- **สะบัด (T231)** — ท่าที่แกว่ง > 0.8 g แล้วนิ่ง 0.3 วิโดยไม่กลายเป็นการเขย่า (`motion::Event::flick`) · ทั้งสะบัดและเขย่าบอก**แรงกระตุกแรกของท่า**
  (`fx/fy/fz` = ค่าที่ใหญ่สุดของการแกว่งช่วงแรก) = ทิศที่ผลักบอร์ด · `ws154Motion()` แปลงเป็นแกนจอ: เซนเซอร์อ่าน +1 g ตามแกนที่ชี้ขึ้น และ
  `Axes{3, 1, 0, 2}` บอกว่าแกนนั้นคือด้านบนของจอเมื่อขอบล่าง (+px / +py) อยู่ล่าง → แรงผลักในแกนจอ = −(fx, fy) แล้วหมุนตาม turn ที่จอแสดง ·
  นับเป็นซ้าย / ขวาเมื่อแกน x ของจอ > 1.4 เท่าของแกนอื่น · **ใช้เฉพาะตอนเปิดเครื่องเล่นเพลง** (หน้าอื่นเหมือนเดิม) · serial log
  `[Motion] flick on the player: push x … -> next / previous` ไว้ตรวจทิศ · **ผู้ใช้ลองเขย่าบอร์ดจริงแล้ว ทำงานได้** (2026-11-21)
- **หยิบ / ขยับ** (> 0.18 g) ตอนจอเป็นนาฬิกาพักจอ = ปลุกจอ · ตอนอื่น = นับเป็นการใช้งาน (เลื่อนเวลาพักจอ)
- **เอียง** = วงคลื่นเลื่อนตามเล็กน้อย (ไฮไลต์ลูกแก้วขยับ)
- console `imu` — ค่าเร่ง/ไจโร/อุณหภูมิ, gravity ที่กรองแล้ว, turn ที่ IMU เห็นกับที่จอใช้, ขาชาร์จ
- แกนของเซนเซอร์ → ขอบจอ: `motion::Axes{3, 1, 0, 2}` (+x = turn 3, −x = turn 1, +y = ล่าง / turn 0, −y = turn 2) — วัดจากผู้ใช้หมุนบอร์ดจริง:
  ค่าที่เดาไว้แรก (+x = turn 1) ซ้าย / ขวาสลับกัน ส่วนกลับหัว 180° ถูกอยู่แล้ว

## เสียง (`AUDIO_ES7210` ใน `AudioManager`)

- ES8311 เล่นเสียง (เหมือนบอร์ดอื่น) · ไมค์ = **ES7210** (`src/audio/ES7210.*`, ลำดับ register ตาม esp_codec_dev ของ Espressif, Apache-2.0)
- **I2S ช่องละ 32 บิต (BCLK 64 fs)** ทั้งสองทาง: ES7210 ในโหมด TDM ส่ง 16 บิตต่อกัน → คำ 32 บิตช่องซ้าย = **MIC1 (ไมค์ที่ใช้)** / MIC2, ช่องขวา = MIC3 / MIC4
  (วัดจริงโดยลด gain ทีละช่อง) · ES8311 รับ 16 บิตแรกของช่อง 32 บิต
- **ไม่มีสายเสียงลำโพงย้อนเข้า ES7210** (MIC3 เงียบสนิทตอนลำโพงดัง) → เสียงอ้างอิงตัดเสียงสะท้อน = **สิ่งที่ส่งออกลำโพง** (`_echoRefRing` 24 kHz แบบบอร์ดไม่มี codec)
- `setMicGain` 0–7 (×6 dB) ปรับ MIC1 (สูงสุด 37.5 dB) · console `adc <reg> [ค่า]` อ่าน/เขียน ES7210 · `audio` แสดงระดับเฉลี่ย 0.5 วิ ของ MIC1–4

## ปุ่ม + ไฟ

| ปุ่ม | กดสั้น | กดค้าง |
|---|---|---|
| VOL− (BOOT) | เสียง AI −10% (ขึ้นป้าย "เสียง 70%") | 1.5 วิ = เมนูตั้งค่า |
| VOL+ | เสียง AI +10% | 1.5 วิ = เปิด/ปิดไมค์ |
| PWR | (< 0.6 วิ) **เปิด / ปิดไมค์** ที่หน้าหลัก (ป้าย "ปิดไมค์" / "เปิดไมค์", วงเป็นสีเทาตอนปิด) · ย้อนกลับในเมนู | 0.6 วิ ขึ้น "ค้างไว้เพื่อปิดเครื่อง…" · 2 วิ = **ปิดเครื่อง** (ใช้แบต: ปล่อยล็อกไฟ · เสียบ USB: หลับลึก กด PWR เพื่อเปิด) · ปล่อยระหว่าง 0.6–2 วิ = ไม่ทำอะไร |

- ล็อกไฟ GPIO 2 = HIGH บรรทัดแรกของ `setup()` · การกด PWR ที่เปิดเครื่องไม่นับเป็นการกด (รอปล่อยก่อน)
- ปุ่มอ่านโดย task `keys` ทุก 10 ms (เดิมอ่านครั้งเดียวต่อเฟรม — กดสั้นในเมนูหลุด) · console `keys` / `keys watch` (ระดับขา) / `keys log` (16 เหตุการณ์ล่าสุด +
  ขอบสัญญาณจาก interrupt) · **ทุกปุ่มจับเวลาด้วย interrupt** (ขอบลง-ขึ้น) แล้ว task `keys` priority 7 วัดเอง — task agent (priority 5) เคยบังจนกดสั้นหลุด
  ("กด PWR 3–4 รอบแล้วค้างที่ปิดไมค์")
- สีวงคลื่น: ความสว่าง < 1 ถูกกดด้วยยกกำลัง 1.8 (จอนี้แสดงโทนมืดสว่างเกินจริง — วงแสงจางๆ เคยเป็นแผ่นสีใหญ่ ทำให้พื้นดำดูเทา)
- แบต: ADC ×3 (เกจ T170 เดิม) + ขาชาร์จ LOW = เสียบ USB อยู่

## ไม่มีหน้าปัดรถ / OBD-II (ผู้ใช้ขอ)
