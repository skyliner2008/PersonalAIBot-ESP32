## โครงสร้าง

- `firmware-p4/` = โปรเจค PlatformIO ของตัวเอง: `platformio.ini`, `partitions_p4.csv`, `include/pins_config.h` (ขาของบอร์ดนี้อย่างเดียว), `src/` (สำเนาจาก `../src`
  แล้วแก้อิสระ — ไม่มี `#if` ของ S3) · ใช้ร่วมกับ repo: `../lib` (Helix MP3/AAC), `../models/srmodels.bin` ("Jarvis" + "Hi ESP" — ชุดของ SDK P4 มีแค่ Hi ESP),
  `../tools/pio_*.py`, wiki, ESP32-AI Studio
- เฟิร์มแวร์ S3 (`../src`, `pio run`) **ไม่มีโค้ด P4 เลย** — งาน P4 ที่เคยใส่รวมไว้ (`#if BOARD_JC4880P443C`) ย้ายมาที่นี่ทั้งหมด
- Build: `pio run -d firmware-p4` (ค่าเริ่มต้น `esp32p4-r3`) · `pio run -d firmware-p4 -e esp32p4` (ชิปก่อน rev 3.0) · แฟลช: `pio run -d firmware-p4 -t upload`
  · ใช้ secrets ของตัวเอง: `firmware-p4/include/secrets.h` (git-ignore, คัดลอกจาก `secrets.example.h`)
- **เลือก env ตามรุ่นชิป** (log ตอนบูตบอก revision): image ของอีกรุ่นบูตไม่ขึ้น

## ขาต่อขยาย (`util/DeviceConfig.h`, devices.json)

ใช้ได้: 1–4, 20, 26–33, 36, 46, 47, 49–52 · analog: **20** (ADC1) และ **49–52** (ADC2 — P4 ไม่มีวิทยุ Wi-Fi ในตัวจึงไม่ชน) ·
**ห้าม 14–19 / 54** (SDIO ของ C6: ใช้แล้ว Wi-Fi หลุด) · 48 = I2S DIN (ไมค์) · 26/27 = UART J5 (OBD) · 35 = ปุ่ม BOOT

## แผนเฟสถัดไป (ดึงความสามารถของบอร์ด)

1. **เฟส 2 — กล้อง + AI มองเห็น:** ไดรเวอร์ OV02C10 บน `esp_cam_sensor` + `esp_video` (ISP → YUV) → JPEG ฮาร์ดแวร์ ~640×480 →
   ส่งเข้า Gemini Live (`realtimeInput.video`, ~1 ภาพ/วิ เฉพาะตอนเปิดกล้อง) + tool `camera` ("ดูให้หน่อยว่านี่คืออะไร", "อ่านป้ายนี้") + ภาพตัวอย่างบนจอ
   (PPA ย่อ/หมุนด้วยฮาร์ดแวร์) · ต้องมีบอร์ดจริงทดสอบ (ค่าลงทะเบียนเซนเซอร์จาก BSP ของ Guition)
2. **เฟส 3 — RS485 / Modbus RTU:** tool `modbus` (อ่าน/เขียน holding/input register, coil) + ตั้งค่า baud/slave ใน devices.json → AI อ่านมิเตอร์ไฟ เซนเซอร์อุตสาหกรรม
3. **เฟส 4 — UI เต็มจอ 800×480:** วาดหน้าหลัก/การ์ด/วิทยุใหม่ที่ความละเอียดจริง (ตอนนี้ UI 320×240 ×2) ใช้ PPA, สี 24-bit
4. ทยอยปรับ OTA/release ให้มีไฟล์ของ P4 แยก (`PersonalAIBot-ESP32P4-*`) — ตอนนี้ release มีแต่ S3 ซึ่งบอร์ด P4 ปฏิเสธเองอย่างปลอดภัย (chip ID)
