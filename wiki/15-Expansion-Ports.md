## พอร์ตที่ยังว่าง (ตรวจจากโค้ด + สแกนบัส I2C บนบอร์ดจริง 2026-10-17)

| คอนเน็กเตอร์ | ขา | ใช้อยู่ | ต่ออะไรได้ |
|---|---|---|---|
| **Expand Pin** (ขอบบนขวา) | **GPIO 2** | ว่าง | digital in/out, PWM, **ADC1** (อ่าน analog ได้ตอน Wi-Fi ทำงาน), touch |
| | **GPIO 3** | ว่าง | เหมือน GPIO 2 (ADC1) · เป็นขา strapping (เลือก JTAG) — อย่าดึง HIGH/LOW แรงๆ ตอนบูต |
| | **GPIO 14** | ว่าง | digital in/out, PWM · ADC2 = **อ่าน analog ไม่ได้ตอน Wi-Fi ทำงาน** |
| | **GPIO 21** | ว่าง | digital in/out, PWM |
| **I2C** (ขอบบนกลาง) | 3.3V, GND, IO15 SCL, IO16 SDA | บัสเดียวกับ codec **0x18** + ทัช **0x38** (400 kHz) | เซนเซอร์ I2C อะไรก็ได้ที่ไม่ใช่ 0x18 / 0x38 (ดูตารางล่าง) |
| **UART** (ขอบล่าง) | 5V, GND, TXD, RXD | เฟิร์มแวร์ไม่ได้ใช้ (`Serial` ไปทาง USB ในตัว) | โมดูล UART 3.3V logic: GPS, PM2.5, เรดาร์ตรวจคน, RS-485 · **สันนิษฐาน**ว่าเป็น UART0 = GPIO 43 (TX) / 44 (RX) — วัดยืนยันก่อน · ตอนบูต ROM พิมพ์ข้อความออก TX |
| ~~ปุ่ม BOOT~~ | GPIO 0 | **ไม่ว่าง**: ปุ่มของหน้าจอ (กดสั้น = แตะ, ค้าง 1.5 วิ = เมนูตั้งค่า, `main.cpp`) | — (ตารางเดิมใน wiki 01 เขียนว่าว่าง: ผิด) |
| แบตเตอรี่ | JST 2 ขา | วัดผ่าน GPIO 9 | LiPo 3.7V |

ขาอื่นทั้งหมดถูกใช้แล้ว (จอ SPI 10–13/45/46, ทัช 15–18, เสียง 1/4–8, SD 38–41/47/48, LED 42, USB 19/20, PSRAM 35–37) — **ห้ามต่อเพิ่ม**

**ไฟเลี้ยง/ระดับสัญญาณ:** GPIO เป็น **3.3V** (ห้ามป้อน 5V เข้าขา), จ่ายกระแสได้ ~20 mA ต่อขา → รีเลย์/มอเตอร์/LED strip ต้องผ่านโมดูลรีเลย์, ทรานซิสเตอร์ หรือ MOSFET
5V จากช่อง UART เลี้ยงโมดูลได้ (ไม่กี่ร้อย mA ตามแหล่งจ่าย USB)

## ต่ออะไรได้บ้าง (ตัวอย่าง)

| อุปกรณ์ | พอร์ต | ใน `devices.json` |
|---|---|---|
| โมดูลรีเลย์ 1–4 ช่อง (ไฟ, พัดลม, ปั๊มน้ำ) | GPIO 21/14/2/3 | `switch` (บอร์ดรีเลย์ส่วนใหญ่ `active_low: true`) |
| LED / LED strip 12V ผ่าน MOSFET, buzzer | GPIO 2/3/14/21 | `dimmer` (PWM 5 kHz) / `switch` |
| ปุ่มกด, สวิตช์ประตูแม่เหล็ก (reed), ลูกลอย | GPIO ใดก็ได้ + GND | `input` (`pull: up`) · `notify: true` = AI แจ้งเมื่อเปลี่ยน |
| PIR ตรวจจับคน (HC-SR501, 3.3V out) | GPIO + 5V | `input` (`pull: down` หรือ `none`, ทำงาน = HIGH) |
| LDR วัดแสง, potentiometer, ความชื้นดิน (analog) | **GPIO 2 / 3** | `analog` (0–3.1 V → volts + %) |
| เซนเซอร์ I2C: อุณหภูมิ/ความชื้น SHT3x (0x44), AHT20 (0x38 ❌ ชนทัช), BME280 (0x76/0x77), แสง BH1750 (0x23), จอ OLED SSD1306 (0x3C), ADC ADS1115 (0x48), ขยาย IO PCF8574 (0x20–0x27), วัดไฟ INA219 (0x40), RTC DS3231 (0x68) | ช่อง I2C | ยังไม่มีไดรเวอร์ — เพิ่มเป็นชนิดใหม่ตามที่ใช้จริง (`i2c` ในคอนโซลสแกนที่อยู่ได้) |
| GPS (NEO-6M), PM2.5 (PMS5003), เรดาร์ตรวจคน (LD2410), RS-485 | ช่อง UART | ยังไม่มีไดรเวอร์ — เพิ่มตามอุปกรณ์จริง |

## ให้ AI สั่งงาน (2026-10-17)

1. เขียน `agent/devices.json` บนการ์ด SD (ตัวอย่าง `tools/sd_card/devices.json`) — หรือส่งจากคอนโซล/Studio: `devices save {"devices":[...]}`
2. บอร์ดโหลดตอนบูต / `devices reload` → session ใหม่: AI เห็นรายชื่ออุปกรณ์ใน prompt + tool **`device`** (list / read / set)
3. พูดได้เลย: "เปิดพัดลม", "หรี่ไฟโต๊ะเหลือ 30", "ประตูปิดอยู่ไหม", "แสงในห้องเท่าไหร่"
   · เรียกด้วยชื่อบางส่วนได้เมื่อมีเครื่องเดียวที่ตรง ("โต๊ะ" = ไฟโต๊ะ) — ถ้าตรงหลายเครื่อง ("ไฟ" กับ ไฟโต๊ะ/ไฟห้องนอน) จะตอบ error ให้ใช้ชื่อเต็ม ไม่เดาตัวแรก (T069, `periph::findByName`)
   · `devices reload` ทาง console ระหว่างที่ agent อ่าน input: poll ข้ามรอบนั้น (ล็อกแบบไม่รอ) ไม่อ่านรายการที่เขียนไปครึ่งเดียว

| type | ค่าที่ตั้ง (`set`) | ค่าที่อ่าน (`read`) |
|---|---|---|
| `switch` | on / off (เปิด/ปิด) | `state` on/off |
| `dimmer` | 0–100 (on = 100) | `level_percent` |
| `input` | — | `state` active/idle · `notify` → `[แจ้งเตือนจากระบบ]` ให้ AI พูด (ปลุกถ้าหลับ, ไม่เกิน 1 ครั้ง/30 วิ/อุปกรณ์) |
| `analog` | — | `volts`, `percent` (ของ 0–3.1 V) |

**ปลอดภัยไว้ก่อน:** รับเฉพาะขาว่างข้างบน (ขาที่จอ/SD/เสียง/ปุ่ม BOOT ใช้ถูกปฏิเสธพร้อมเหตุผลใน `devices` → `errors`), analog เฉพาะ GPIO 2/3,
สูงสุด 8 อุปกรณ์, switch เริ่มที่ "ปิด" ตอนบูต · ไม่มีอุปกรณ์ = ไม่ประกาศ tool (ไม่เสีย token)

**คอนโซล:** `devices` (รายการ + errors) · `devices reload` · `devices save <json>` · `device <ชื่อ>` (อ่าน) · `device <ชื่อ> on|off|0-100` · `i2c` (สแกนบัส)

**ทดสอบบนบอร์ด:** ไฟล์ 5 รายการ (มีขา 10 ผิด 1) → โหลด 4 ปฏิเสธ 1 พร้อมเหตุผล · `device ไฟทดสอบ on`, `ไฟหรี่ 40`, อ่าน `แสง` (ขาลอย 2.4–3.1 V) ✓
· **AI สั่งเอง (พิมพ์ถาม):** "เปิดไฟทดสอบ แล้วหรี่ไฟหรี่เหลือ 20%" → `device set` 2 ครั้ง · "ค่าแสงเท่าไหร่ ปุ่มบูตกดอยู่ไหม" → `device read` 2 ครั้ง · "ปิดไฟทดสอบ" ✓
· ทดสอบแจ้งเตือนด้วยปุ่ม BOOT ไม่ได้ (อ่าน idle 30 ครั้งแม้ผู้ใช้กด) → พบว่า GPIO 0 เป็นปุ่มของหน้าจออยู่แล้ว → ตัดออกจากขาว่าง · การแจ้งเตือนของ `input` ยังรอทดสอบกับสวิตช์จริง (เช่น สายจาก GPIO 14 ลง GND)

## ต่อยอด
- ไดรเวอร์ I2C ตามที่ใช้จริง (SHT3x / BME280 / BH1750 เป็นตัวเลือกแรก) และ UART (LD2410 ปลุก AI เมื่อมีคนเข้าห้อง)
- แก้ `devices.json` จากหน้า ESP32-AI Studio
- ตั้งเวลา/เงื่อนไข ("เปิดพัดลมตอนบ่ายสอง") ผ่านระบบแจ้งเตือนเดิม
