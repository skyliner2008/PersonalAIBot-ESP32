## เอนจินดวงตา (Eyes.cpp)

ตาแต่ละข้าง = สี่เหลี่ยมมุมโค้ง (w, h, radius) แล้ว "ตัด" ด้วยสีพื้นหลัง:
- **เปลือกตาบน** `lidTop` (ความลึก) + `tilt` (+ เอียงลงหาจมูก = โกรธ, − เอียงลงด้านนอก = เศร้า)
- **เปลือกตาล่าง** `lidBottom` (ตัดตรง)
- **แก้ม** `cheek` = วงรีดันขึ้นจากด้านล่าง → ตาพระจันทร์เสี้ยว ^ ^ (ยิ้ม)
- เสริม: **หัวใจ** (love), **แก้มแดง** (blush), **Zzz** (หลับ)

ทุกพารามิเตอร์ขับด้วย **สปริงแบบ under-damped** (k=170, d=13 → overshoot ~15%) ทำให้เปลี่ยนอารมณ์แล้ว "เด้ง" +
- **kick**: แรงกระตุ้นขนาด (pop) ตอนเปลี่ยนอารมณ์ / ตื่น / ตอนพูดพยางค์หนัก
- **กะพริบ** ทุก 2.2–5.6 วิ (บางครั้งกะพริบสองที) ปิด 70 ms เปิดแบบ ease-out-back
- **มองไปมา** แบบสุ่ม (saccade) + กะพริบตอนกลอกตาไกล, หายใจ (ขยับขึ้นลง ±1.6 px)
- **พูด**: squash & stretch ตามระดับเสียง (RMS) ของลำโพง

### อารมณ์ (14) — `set_expression` จาก AI หรืออัตโนมัติตามสถานะ
`neutral` `happy` `excited` `love` `sad` `worried` `angry` `surprised` `sleepy` `thinking` `curious` `confused` `shy` `wink`
(ภาพจริงจากบอร์ด: happy = เสี้ยว+แก้มแดง, love = หัวใจชมพู, angry/sad = เปลือกตาเอียงตรงข้าม, surprised = กลมโต, wink/shy/confused/thinking ไม่สมมาตร)

| สถานะ agent | โหมดตา | อารมณ์พื้นฐาน |
|---|---|---|
| CONNECTING | กลอกตาซ้ายขวา (searching) | neutral |
| IDLE | สุ่มมอง + กะพริบ | neutral |
| LISTENING | ขยาย 6% มองผู้ใช้ | neutral |
| THINKING | มองขึ้นซ้าย + saccade | thinking |
| SPEAKING | เด้งตามเสียง | (ตามที่ AI ตั้ง) |
| SLEEP | ปิดเป็นเส้น + Zzz | sleepy |
| SETUP (ยังไม่ตั้งค่า) | — | curious + เฟืองกะพริบ |
| ERROR | — | worried |

สีตา 8 สี (ตั้งได้จากเมนู/เสียง/โปรไฟล์)

## โหมดนาฬิกา ประหยัดพลังงาน (v3.2.1)

```
คุยอยู่ ──เงียบ sleepMinutes (3)──► พัก: ตาหลับ + zZ, ปิดเซสชัน Gemini (ไม่เสียโทเคน)
        ──อีก clockMinutes (5)──► นาฬิกา: เวลาใหญ่ (7-segment) + วันที่ไทย + ตาหลับเล็กๆ, จอหรี่เป็น dimBrightness (8%)
พัก: ได้ยินเสียงพูด (VAD ในเครื่อง, ไมค์เปิด) หรือแตะจอ ──► ตื่น → ต่อ AI (เสียงที่พูดระหว่างต่อถูกเล่นต่อให้ AI)
นาฬิกา: ไมค์ปิด (v3.4, ผู้ใช้เลือก) — แตะจอ / กด BOOT เท่านั้น ──► จอสว่างเท่าเดิม → ตื่น → ไมค์เปิด
```

![[images/clock-face.png]]

- `FaceScreen::drawClock` — รองรับ **4 ธีมพักหน้าจอ** พร้อมแสดงสภาพอากาศสดและ PM2.5 ของเมืองที่เลือก (`set clocktheme 0..3`, `set city <ชื่อจังหวัด|auto>`):
  1. **ดิจิทัล + สภาพอากาศ (ค่าเริ่มต้น)**: เวลา 7-segment + วินาที + วันที่ไทย + การ์ดกราฟิกสภาพอากาศ, ความชื้น และป้ายสี PM2.5
  2. **สมาร์ทวอช วงแหวน**: หน้าปัดวงกลม 60 ขีดวินาทีเรืองแสงตามสีดวงตา + การ์ดวันที่และสภาพอากาศด้านขวา
  3. **ฟลิปการ์ด ไซเบอร์**: การ์ดตัวเลขพับคู่แยกชั่วโมง/นาทีขอบนีออน + วันที่ไทย + การ์ดสภาพอากาศด้านล่าง
  4. **คลาสสิก มินิมอล**: ดวงตาหลับ + เวลา 7-segment ขนาดใหญ่พิเศษ + วันที่ไทย + บรรทัดสรุปสภาพอากาศ
- ขยับพิกเซล ±4 px ทุกนาที (กันภาพค้างบนจอ IPS) · ดึงสภาพอากาศเบื้องหลังทุก 20 นาทีผ่าน `WebTools` โดยไม่ต้องใช้ geocoding สำหรับ 77 จังหวัดไทย
- task UI วาดใหม่ทุก 0.5 วิ และ poll ทุก 40 ms ระหว่างเป็นนาฬิกา (ปกติ ~60 fps) — ลด SPI/CPU
- ตั้งค่า: เมนู ⚙ → **จอ & พักจอ** → เลือก "ธีมพักหน้าจอ", "เมืองสภาพอากาศ" (เลือกจาก 5 ภาค 77 จังหวัด หรือพิมพ์เอง), "ดูตัวอย่างพักหน้าจอ", "โหมดนาฬิกา ประหยัดไฟ" (1/3/5/10/30 นาที/ไม่ใช้) + "แสงจอตอนพักหน้าจอ" (แตะวน 4/8/15/25%) • console `set clocktheme <0-3>` / `set city <จังหวัด|auto>` / `set batmode <0-2>` • ทดสอบทันที: console `powersave`
- `diag` มี `power_save`; ถ้า**ปิดไมค์**อยู่ จะปลุกด้วยเสียงไม่ได้ (แตะจอแทน)
- ไอคอนไมค์มุมซ้ายบน: **เขียว = เปิด** (รวมตอนหลับ — พูดปลุกได้) · ฟ้า = กำลังได้ยิน · แดง+ขีด = ปิด (v3.4: เดิมสีเทาจางดูเหมือนปิด — T051)

### สีจอ (IPS)
แผง IPS ILI9341V ต้องเปิด color inversion (INVON) จึงจะได้พื้นดำ/ตัวอักษรขาวตามที่วาด — ค่า `lcdInvert` (ค่าเริ่มต้นเปิด)
สลับได้ที่เมนู "พื้นจอเป็นสีขาว? แตะเพื่อสลับสี", `set invert 0|1` หรือ PC app · screenshot อ่านจาก framebuffer จึงเห็นพื้นดำเสมอไม่ว่าจอจริงจะกลับสีหรือไม่
([[07-Troubleshooting-Log#T029 จอพื้นขาว ตัวอักษรดำ - จอ IPS ต้องเปิด color inversion]])

### Touch mapping
- FT6336 ถูกอ่านผ่าน `I2cBus` (Wire + mutex) ไม่ใช่ไดรเวอร์ทัชของ LovyanGFX
- ค่าเริ่มต้นแปลงพิกัดแบบเดียวกับ LovyanGFX `convertRawXY` (rotation 1: x = raw_y, y = 239 − raw_x)
- วัดบนบอร์ดจริง: ทัชหมุน 180° เทียบกับ LCD → ค่าเริ่มต้นใช้ `rotation ^ 2`
- และมี **Calibration 3 จุด** (ขึ้นอัตโนมัติตอนบูตแรก / เมนู "ปรับการแตะหน้าจอ") คำนวณแกน การกลับด้าน และสเกลแบบ linear ต่อแกน เก็บใน NVS
