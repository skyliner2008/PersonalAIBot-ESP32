# 26 — บอร์ด Guition JC3248W535 (ESP32-S3 จอ 3.5" 320×480, AXS15231B)

> **Related:** [[25-ES3C35P-3.5inch]] (จอ 3.5" อีกรุ่น — อย่าสับสน) · [[07-Troubleshooting-Log#T221]] · [[07-Troubleshooting-Log#T220]] · [[17-Mobile-Flasher]] · [[15-Expansion-Ports]]

**Guition JC3248W535** (บนแผ่นพิมพ์ "SC3248W535", หน้าร้านไทยบางร้านเขียน ILI9488 + GT911 ซึ่ง**ผิด** — ใบสเปคของบอร์ดบอก AXS15231B) —
ESP32-S3-N16R8 (flash 16 MB, PSRAM 8 MB Octal), IPS 3.5" 320×480, ชิปจอ + ทัช **AXS15231B** (จอ QSPI, ทัช I2C 0x3B),
แอมป์ I2S ต่อลำโพง (ช่อง SPEAK JST 1.25-2P), ช่อง TF (ต่อแบบ SPI), แบต, ปุ่ม BOOT / RST / BAT_Key, ขาเสริม 12 ขา
· **ไม่มีไมโครโฟนบนบอร์ด** และไม่มีไฟ RGB

**ที่มา:** ผู้ใช้แฟลชเฟิร์มแวร์ "S3 จอ 3.5"" (ES3C35P) ลงบอร์ดนี้แล้วจอเป็นจุดสี — ES3C35P ขับชิปจอ ST77922 คนละขา (wiki 07 T220/T221)
→ build แยก `pio run -e jc3248w535` (ซอร์สเดียวกับ ES3C28P / ES3C35P) · release: `-factory-jc3248w535.bin` / `-app-jc3248w535.bin`

## ขา (จากใบสเปค / config ที่ใช้งานจริง: done.land, ESPHome, Arduino_GFX `JC3248W535`, JC3248W535-Driver)

| หน้าที่ | JC3248W535 | ES3C35P (เทียบ) |
|---|---|---|
| จอ | **AXS15231B QSPI**: CS 45, CLK 47, D0–D3 21 / 48 / 40 / 39, ไม่มีขา reset (software reset) | ST77922 QSPI: CS 10, CLK 12, D0–D3 11 / 13 / 14 / 9 |
| ไฟจอ | **1** (ผ่าน Q2, HIGH = ติด, PWM) | 41 |
| ทัช | **AXS15231B ในตัว, I2C 0x3B**: SDA **4** / SCL **8** (schematic เขียนสลับกัน), INT 3 | ST77922 0x55 ที่ 38 / 39 |
| เสียงออก | **แอมป์ I2S** (U4 — NS4168 / MAX98357): BCLK 42, LRCLK 2, DIN 41 · ไม่มี codec | ES8311 + FM8002E |
| ไมค์ | **ไม่มี** → ต่อไมค์ I2S ภายนอก (INMP441): **SCK IO15, WS IO16, SD IO7**, L/R → GND, VDD → 3V3 | ES8311 |
| SD | ต่อแบบ SPI: CS 10, MOSI 11, CLK 12, MISO 13 → ใช้ **SDMMC 1-bit** บนสายเดียวกัน (CMD 11, CLK 12, D0 13, D3/CS 10 ค้าง HIGH) | SDMMC 4-bit |
| แบต ADC | **5** (ADC1_CH4) ผ่าน 33k/100k → Vbat = Vadc × **1.33** | 8 (×2) |
| ไฟ RGB | ไม่มี | 40 |
| ช่องเสริม (devices.json) | P2: **6, 9** (ADC1), 14 · P3/P4: 17, 18 · UART 43 / 44 (7 / 15 / 16 = ไมค์) | 45, 46 + UART |
| BOOT | 0 | 0 |

## จอ AXS15231B

- LovyanGFX 1.2.33 ไม่มี AXS15231B → `Panel_AXS15231B` (`src/display/LGFX_JC3248W535.hpp`) = `Panel_ST77916` (QSPI framing เดียวกัน: คำสั่ง `02 00 cmd 00`,
  พิกเซล `32 00 cmd 00` + 4 สาย) + init table "type1 320×480" ของ Arduino_GFX (BSD — มีประกาศ license ในไฟล์; เป็นตารางเดียวกับที่ Arduino_GFX ใช้กับ
  JC3248W535) + SWRESET นำหน้า (ไม่มีขา reset) · ไม่ invert, MADCTL RGB
- **ข้อจำกัดของชิป (QSPI):** ไม่รับที่อยู่แถว (RASET) แบบปกติ — เฟรมต้องเขียนจากบนลงล่าง: แถบที่เริ่มแถว 0 ใช้ RAMWR (0x2C), แถบต่อไป RAMWRC (0x3C)
  (วิธีเดียวกับ `esp_lcd_axs15231b` ของ Espressif) → `setWindow()` ส่ง CASET ทุกครั้ง, RASET 0–479 เฉพาะแถว 0 แล้วจำว่าเขียนต่อด้วย 0x2C หรือ 0x3C
- ไม่มีการสลับแกนในฮาร์ดแวร์ → ใช้ทางเดียวกับ ES3C35P: แผงจอแนวตั้งเสมอ, `UiManager::present()` หมุน + ขยาย UI 320×240 ทีละ 8 แถวเต็มจากบนลงล่าง
  (`#if defined(BOARD_ES3C35P) || defined(BOARD_JC3248W535)`) · QSPI 40 MHz ตามตัวอย่างผู้ผลิต
- ทัช: `src/display/TouchAXS15231B.h` — เขียนคำสั่ง 11 ไบต์ `B5 AB A5 5A 00 00 00 08 00 00 00` อ่าน 8 ไบต์ ([1] = จำนวนจุด, x/y 12 บิต) ผ่าน
  `I2cBus::writeThenRead()` · พิกัดแกนเดียวกับ ST77922 (x 0–319, y 0–479) → ใช้ `TouchST77922::toRaw()` แปลงเหมือนกัน

## เสียง (ไม่มี codec)

- `AUDIO_SIMPLEX` (เปิดใน `AudioManager.h` สำหรับบอร์ดนี้) → `src/audio/AudioSimplex.cpp` (มาจากเสียงของ XH-S3E-AI ใน firmware-s3-mini):
  ลำโพง I2S0 16-bit **stereo ซ้ำกันสองช่อง** (แอมป์จะเลือกช่องไหนก็ดังได้) 24 kHz · ไมค์ I2S1 16 kHz 32-bit mono left · เสียงอ้างอิงตัดเสียงสะท้อน =
  สิ่งที่ส่งออกลำโพง (แม่นกว่า loopback) · ความดังเป็นแบบดิจิทัล (ยกกำลังสอง)
- ขา SD ของไมค์เปิด pull-down: ไม่ได้ต่อไมค์ = เงียบ (ไม่ใช่ noise ที่ทำให้ตื่นเอง) · เงียบสนิท 10 วิ → log
  `[Audio] mic: no signal - this board has no microphone of its own: connect an I2S MEMS mic (INMP441: SCK IO15, WS IO16, SD IO7 ...)`
- ไม่ต่อไมค์: ยังใช้ได้ — จอ, ทัช, วิทยุ / เพลง, แชทพิมพ์จากแอป / Studio (AI ตอบเป็นเสียง), หน้าปัด, ข้อมูล — แต่สั่งด้วยเสียง / คำปลุกไม่ได้

## แอปแฟลช

- ESP32-AI Flasher (Windows 2.2.0): ลายเซ็น = ทัช AXS15231B 0x3B ที่ SDA 4 / SCL 8 → "อัตโนมัติ" เลือกบอร์ดนี้ได้แม้ขา 38/39 จะอ่านเป็นดึงขึ้นเหมือน ES3C35P ·
  เลือก ES3C35P กับบอร์ดนี้ = ปฏิเสธ "ชิปบนบอร์ดตรงกับ JC3248W535 ให้เลือกรุ่นนั้น" · สแกนบอร์ดแสดง "✔ ชิปบนบอร์ดตรงกับ JC3248W535"
- Studio / Flasher Android (2.1.3): รู้จัก `jc3248w535` (pull-up 4/8) — ถ้า 38/39 ก็ขึ้นด้วยจะให้เลือกรุ่นเอง (ไม่มีการถามชิป I2C)
