# 🖥️ ESP32-AI Studio — แอปบน PC สำหรับตั้งค่า เครื่องมือ และ debug log

> **Related:** [[00-Home-Dashboard]] | [[09-Assistant-Profiles-and-Tools]] | [[06-Avatar-and-Thai-UI]] | [[07-Troubleshooting-Log]]
> **Code:** `tools/pc_app/esp32_ai_studio.py` (ไฟล์เดียว, Python + Tkinter + pyserial) · `tools/pc_app/run_studio.bat`

ต่อบอร์ดผ่าน USB (serial 115200) แล้วจัดการทุกอย่างจาก PC — ไม่ต้องพิมพ์บนคีย์บอร์ดจอเล็ก

## เริ่มใช้งาน

```powershell
tools\pc_app\run_studio.bat                 # ติดตั้ง pyserial ให้ถ้ายังไม่มี แล้วเปิดแอป
# หรือ
python -m pip install pyserial
python tools\pc_app\esp32_ai_studio.py
```

- แอปเลือกพอร์ตบอร์ดให้อัตโนมัติ (Espressif / USB Serial มาก่อน) และ**ไม่รีเซ็ตบอร์ด**ตอนเปิดพอร์ต (DTR/RTS = off)
- ปิด `pio device monitor` ก่อน — พอร์ต COM เปิดได้ทีละโปรแกรม
- ต้องใช้เฟิร์มแวร์ **3.1.0+** (มีคำสั่ง `config/options/tools/diag/...`)

## วินิจฉัยไมค์: log `[Mic]` + อัดเสียง

log สีเขียวอมฟ้า `[Mic]` บอกทุกครั้งว่าไมค์ส่งอะไรให้ AI (คำเตือน ⚠ เป็นสีส้ม):

| log | ความหมาย |
|---|---|
| `[Mic] เริ่มส่งเสียงให้ AI (ระดับ…, เกณฑ์…, ขยาย x…)` | ตรวจพบเสียงพูด เริ่มส่ง (รวม pre-roll 0.6 วิ) |
| `[Mic] ฟังต่อ 6 วิ หลัง AI ตอบ` | หลัง AI พูดจบ ส่งเสียงต่อเนื่องเพื่อรับคำตอบเร็วๆ |
| `[Mic] จบประโยค: ส่ง 2.4 วิ (เสียงพูด 1.8 วิ, ดังสุด …) -> รอ AI ตอบ` | ส่งครบแล้ว + `audioStreamEnd` |
| `[Mic] ได้ยินเสียงสั้นๆ … ไม่ถึงเกณฑ์ - ไม่ได้ส่ง` | ไอคอนกะพริบแต่ไม่พอจะส่ง (เสียงเบา/สั้น) |
| `[Mic] ⚠ ส่งเสียงพูดแล้วแต่ AI ไม่ได้ยิน/ไม่ตอบใน 8 วิ` | ส่งแล้วไม่มี transcript/คำตอบ → เสียงไม่ชัด หรือ 3.8 เลือกไม่ตอบ |
| `[Mic] ⚠ AI ได้ยินแล้ว (มี transcript) แต่ไม่ตอบใน 8 วิ` | ฝั่งโมเดลไม่ตอบ (proactive audio ของ 3.8) |

**แท็บเครื่องมือ → "อัดเสียงที่ AI ได้ยิน"**: ⏺ อัด 1–8 วิ (คำสั่ง `rec`) → ได้ไฟล์ `recordings/rec_YYYYmmdd_HHMMSS.wav`
(เสียงหลัง AGC = สิ่งที่ส่งให้ Gemini จริง) เล่นอัตโนมัติ + กราฟระดับต่อ 40 ms (ฟ้า = ส่งให้ AI, ส้ม = ได้ยินแต่ไม่ได้ส่ง, เส้นแดง = เกณฑ์)
+ สรุป: ระดับเสียงพูด/พื้นหลัง (dBFS), ดังสุด, clip, จำนวนช่วงที่ส่ง, อัตราขยาย

**ความไวไมค์**: แท็บตั้งค่า → เครื่อง → "ความไวไมค์ (0-7)" (ทีละ 6 dB, ค่าเริ่มต้น 6) — ต้องพูดใกล้บอร์ด = เพิ่ม, เสียงแตก/เก็บเสียงรอบข้างมาก = ลด
**Google Search**: ผลทดสอบ API key มีบรรทัด "Google Search (grounding)" แยก · ปุ่ม "ลองเปิด Search ใหม่" (แท็บตั้งค่า → โมเดล AI ข้างช่อง Google Search)

## คัดลอก / วาง

- **Ctrl+C / Ctrl+V / Ctrl+X / Ctrl+A** ใช้ได้ทุกช่อง **ทั้งคีย์บอร์ดไทยและอังกฤษ** (Tk ปกติจับปุ่มจากตัวอักษร พอเป็นแป้นไทยจึงไม่ทำงาน — แอปจับจาก key code แทน)
- **คลิกขวา** ที่ช่องข้อความ = เมนู ตัด / คัดลอก / วาง / เลือกทั้งหมด / ล้างช่องนี้ · ช่องอ่านอย่างเดียว (log, ผลลัพธ์, แชท) = คัดลอก / เลือกทั้งหมด / **คัดลอกทั้งหมด**
- แท็บ Debug log: ปุ่ม **📋 คัดลอก log** = คัดลอกส่วนที่เลือก หรือทุกบรรทัดที่แสดงอยู่ (ตามตัวกรอง) ถ้าไม่ได้เลือก
- ช่องรหัสผ่าน/API key (ซ่อนอยู่) คัดลอกออกมาได้เป็น `•••` เท่านั้น — วางเข้าได้ตามปกติ

## Protocol (serial console)

คำสั่งเป็นข้อความบรรทัดเดียว (ดู `help` บนบอร์ด) — คำตอบที่แอปอ่านเป็น **หนึ่งบรรทัด `<TAG> <json>`**

| คำสั่ง | คำตอบ | เนื้อหา |
|---|---|---|
| `config` | `CONFIG {...}` | ค่าตั้งทั้งหมด (ไม่มี key/รหัส: `keySet`, `keyLen`, `keyHint`, `passSet`) |
| `options` | `OPTIONS {...}` | profiles, voices (เพศ/สไตล์), personalities, eyes (#RGB), genders, liveModels, textModels, thinking |
| `tools` | `TOOLS [...]` | function declarations ของ AI (ชื่อ, คำอธิบาย, parameters) |
| `diag` | `DIAG {...}` | สถานะ runtime (รันใน agent task — ข้อมูลสอดคล้องกัน) |
| `wifiscan` | `WIFISCAN [...]` | ssid, rssi, secure |
| `apitest` | `APITEST {...}` | ผลทดสอบ key (หลายวินาทีต่อมา) |
| `rec <วิ>` | `RECINFO {...}` + `RECORD <rate> <n>` + n ไบต์ PCM16 + `END` | เสียงที่ส่งให้ AI + ธง VAD ต่อ chunk (`flags`: bit0 เสียงพูด, bit1 ส่งแล้ว) |
| `tool <name> <json>` | `TOOL <name> {...}` | ผลของ tool |
| `screenshot` | `SCREENSHOT w h n` + n ไบต์ RGB565 big-endian + `END` | ภาพจาก framebuffer |
| `set <field> <value>` | `OK set ...` / `ERR set ...` | บันทึก NVS ทันที |
| `ask <text>` | `OK ask` แล้ว log `[Chat] ...` | ข้อความถึงผู้ช่วย |

บรรทัด log ปกติขึ้นต้นด้วย `[Agent]`, `[Gemini]`, `[Fallback]`, `[Chat]`, `[WiFi]`, `[Touch]`, `[Health]` หรือ `E (...)` (ESP-IDF error)

## ความปลอดภัย

- เฟิร์มแวร์**ไม่เคยพิมพ์** API key หรือรหัส Wi-Fi ออก serial · แอปซ่อน `key=...` ใน log และแสดงคำสั่ง `set key`/`set pass`/`set mt5token` เป็น `***` (`config` แสดงแค่ `mt5tokenSet`)
- ไฟล์ที่ส่งออกจากแท็บตั้งค่า**ไม่มี** API key / รหัส Wi-Fi
- รหัส Wi-Fi / API key / MT5 token เก็บแบบ**เข้ารหัส AES-256-GCM ผูกกับชิป** ในการ์ด SD (`agent/secrets.json`; ไม่มีการ์ด = NVS) — ช่อง API key แสดง 🔒 พร้อมที่เก็บ • ปุ่ม **💾 ไฟล์สำหรับการ์ด SD...** สร้าง `ai-setup.txt` จาก Wi-Fi / key ที่กรอก ([[07-Troubleshooting-Log#T042 รหัส Wi-Fi และ API key เก็บเป็นข้อความธรรมดาในแฟลช]])
