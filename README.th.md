## ✨ ทำอะไรได้บ้าง

คุยกับมันได้เหมือนคุยกับคน — ภาษาไทยหรืออังกฤษ มันตอบด้วยเสียงที่เป็นธรรมชาติ แสดงอารมณ์ด้วยดวงตาบนจอ
จำเรื่องของคุณข้ามวันได้ และดึงข้อมูลสด (อากาศ, ราคาน้ำมัน, หุ้น, ข่าว ฯลฯ) มาแสดงเป็นกราฟิกบนจอระหว่างที่อธิบาย
ทุกอย่างทำงานบนบอร์ดเอง: **ไม่ต้องมี server, ไม่ต้องมี Raspberry Pi, ไม่ต้องมี vector database** — ใช้แค่ Wi-Fi กับ Gemini API key

| 🧑‍💼 **บุคลิก** | โปรไฟล์สำเร็จรูป 8 แบบ (ไข่มุก, ภูมิ, ลีน่า, ธันวา, มะปราง, โอม, น้ำ, ครูเก่ง), เสียง 30 แบบ, นิสัย 7 แบบ, ลงท้าย ค่ะ/ครับ — เปลี่ยนผ่านเมนูทัชหรือสั่งด้วยเสียง |
| 👀 **ใบหน้ามีชีวิต & เมนูสมาร์ทวอช** | ดวงตาสไตล์ Cozmo 14 อารมณ์, ซับไตเติลภาษาไทย, ไอคอนคมชัดแบบ anti-aliased (ปุ่มไมค์มุมซ้ายล่าง), status bar สูงเท่ากัน (Wi-Fi แบบพัด + เวลา Oswald), ตรวจจับไฟ `USB ⚡` / `% แบต` อัตโนมัติ (T170: แยก USB / แบตจากการกระโดดของแรงดันตอนเสียบ/ถอด + สัญญาณ USB ของ PC, % เปลี่ยน ≤ 1 %/นาที - บน USB ขึ้นอย่างเดียว บนแบตลงอย่างเดียว - และ `% ⚡` ตอนชาร์จ; console `bat`), ปุ่มลัดมุมขวาล่างเปิดได้ทั้ง **เครื่องเล่น วิทยุ/MP3 (`♫`)** และ **หน้าปัดรถ**, พร้อม **เมนูตั้งค่าสไตล์สมาร์ทวอช** (การ์ดไอคอนสีสันสดใส 8 หมวด 2 หน้า ปัดซ้าย/ขวาได้) — พักนานจะเปลี่ยนเป็น**หน้าจอพักนาฬิกาหรี่แสง 7 ธีม** (*ดิจิทัล + สภาพอากาศ*, *สมาร์ทวอช วงแหวน*, *ฟลิปการ์ด ไซเบอร์*, *คลาสสิก มินิมอล*, *อนาล็อก เข็มนาฬิกา*, *ตัวเลขใหญ่ ตั้งโต๊ะ*, *ดวงอาทิตย์ & ดวงจันทร์*) เลือก**สีนีออนได้ 9 สี** (ฟ้า เขียว ชมพู ส้ม เหลือง ม่วง แดง ขาวนวล หรือตามสีดวงตา) นาฬิกาใหญ่เต็มจอ แสดงเวลา วันที่ไทย และสภาพอากาศสด + PM2.5 ของจังหวัดที่เลือก และตื่นพร้อมจอสว่างทันทีที่ได้ยินคำปลุกหรือแตะจอ |
| 📊 **การ์ดข้อมูลสด** | อากาศ + PM2.5, ราคาน้ำมันไทย, หุ้น/ทอง/คริปโต/ค่าเงิน, วิเคราะห์เทคนิค, สแกนหุ้น, ปฏิทินเศรษฐกิจ, ข่าว, Wikipedia — วาดเป็นกราฟิกขณะ AI พูด |
| 📻 **วิทยุออนไลน์** | หน้าจอแบบแอปวิทยุ พร้อม 16 สถานีไทยที่ทดสอบแล้ว (เพิ่มได้ถึง 40 — `python tools/radio_check.py` ตรวจรายชื่อสถานีแบบเดียวกับที่บอร์ดเล่น; ถอดรหัส AAC ที่เฟรมเสียไม่ค้างจนรีบูตแล้ว): เลื่อนแล้วแตะเลือกสถานี ปุ่มเพิ่ม/ลดเสียง ปุ่ม ⏸ หยุดชั่วคราว ปุ่ม ⏻ ปิดวิทยุ (สีแดง) และแตะกลางจอเพื่อสั่งงาน AI ได้เหมือนเดิม พูด "เปิดวิทยุลูกทุ่ง" หรือ "สถานีที่ 4" แล้ว AI จะเลือกจากรายการให้ แก้รายการ (เพิ่ม แก้ ลบ เรียงลำดับ ทดสอบ URL) ได้ใน ESP32-AI Studio ถอดรหัส MP3/AAC ด้วย Helix และวิทยุจะเบาลงเหลือ 12% ระหว่างคุย ปุ่มปรับเสียงและคำสั่ง "เบาเสียงหน่อย" ปรับเฉพาะวิทยุ — เสียง AI ล็อกไว้ที่ระดับของตัวเอง (ค่าเริ่มต้น 80, `set aivolume`) สั่งเปิดวิทยุแล้ว AI บอกชื่อสถานีแล้วพักทันที (ไม่ฟังหรือตอบเสียงดีเจ) และสั่ง "เปิดวิทยุ" เฉยๆ จะเล่นสถานีล่าสุด ถามข้อมูล (อากาศ ข่าว ...) ระหว่างเปิดวิทยุ เซสชันจะรอจน AI ตอบเสร็จ (T119) **เพลง MP3 จาก SD card (T122):** ปุ่มสลับ [วิทยุ | MP3] บนหน้าวิทยุ เล่นเพลงในโฟลเดอร์ `music` ของ SD card (และโฟลเดอร์ย่อย 1 ชั้น) แสดงชื่อเพลงและศิลปินจาก ID3 tag (รองรับ tag ภาษาไทย) หรือชื่อไฟล์ จบเพลงเล่นเพลงถัดไป หยุดแล้วเล่นต่อจากจุดเดิม สั่งด้วยเสียง "เปิดเพลง ...", "เปลี่ยนเพลง", "เพลงก่อนหน้า", "สุ่มเพลง" หรือ console `music` ถ้าการ์ดหยุดตอบ บอร์ด mount ใหม่เองโดยไม่ต้องรีบูต (T125) **ใส่เพลงจาก PC (T123):** ESP32-AI Studio → แท็บ 🎵 เพลง (SD) ส่งไฟล์ MP3 ลงการ์ดผ่านสาย USB (ตรวจ sha256, ~140 KB/s ≈ 1 นาทีต่อเพลง 8 MB) ดูรายการ เล่น และลบได้ — ใช้ตัวถอดรหัสเดียวกับวิทยุ ไม่กิน RAM เพิ่ม [wiki/12](wiki/12-Internet-Radio.md) |
| 🏁 **หน้าปัดรถ** (ใหม่, **เฉพาะ ES3C28P** — ไม่มีในเฟิร์มแวร์ P4 และบอร์ดจิ๋ว) | หน้าปัดรถยนต์และมอเตอร์ไซค์ 3 รูปแบบ — **รถแข่ง** (บาร์รอบ), **วงกลมดิจิทัล สปอร์ต** (วงแหวนไฟ) และ **เข็มวงกลม คลาสสิก** (วัดรอบ + ความเร็ว) — มี shift light, ความเร็ว, เกียร์, ช่องอุณหภูมิเครื่อง / แบต / อากาศเข้า เปลี่ยนเป็นเหลือง/แดงเมื่อเกินเกณฑ์ เปิดด้วยปุ่มรูปหน้าปัดมุมขวาล่างของหน้าหลัก หรือพูด "เปิดหน้าปัด" (ยังไม่ได้เลือกแหล่งข้อมูล = เปิดตัวจำลองให้) แตะแถบหัวเพื่อสลับแบบ ข้อมูลจาก **Honda K-Line** (Wave 110i / 125i, Click, PCX ... ผ่านบอร์ดแปลงแบบ L9637D), OBD-II ผ่าน ELM327 ต่อสาย, ข้อความจากบอร์ดอื่น หรือตัวจำลองในตัว (นิ้วเป็นคันเร่ง) — ELM327 แบบ Bluetooth LE (หรือ dual-mode) ใช้เฟิร์มแวร์แยก `pio run -e esp32s3-ble -t upload` (ไม่อยู่ใน release ตั้งแต่ T192 — RAM ~23 KB ของบลูทูธให้สตรีมราคาสดแทน) — ตั้งแต่ T113 ใช้ OBD ผ่านบลูทูธพร้อมผู้ช่วยเสียงได้ (ย้าย buffer/ออบเจกต์ไป PSRAM, pool ของ NimBLE อยู่ใน PSRAM, ฟังคำปลุกคำเดียวขณะใช้บลูทูธ; บลูทูธเปิดเฉพาะตอนเปิดหน้าปัด ปิดหน้าปัดแล้วได้ RAM คืน) **ล็อกภาษาของ AI (T116):** ตั้งค่า "ภาษาที่ AI พูด" ไทย (ล็อก, ค่าเริ่มต้น) / English / ตามภาษาที่ผู้ใช้พูด (`set language th` / `en` / `auto`, Studio) **log OBD + เล่นย้อนหลัง (T115; ตรวจ log จากรถจริงครั้งแรกใน T117: แก้ VIN ที่รถตอบ "รอสักครู่"):** ทุกคำสั่ง/คำตอบของ adapter สถานะ เหตุการณ์ ค่าทุกวินาที รหัสปัญหา และสุขภาพรถ ลง SD card (`agent/obdlog`, sync ทุก 2 วิ) ดึงลง PC ด้วย `python tools/obd_log.py` (`pull`, `summary`, `csv`, `replay`) และแหล่งหน้าปัด "เล่นย้อนหลังจาก log" เล่นการขับที่บันทึกไว้ผ่านตัวคุยกับ ELM327 ตัวเดิม — อัปเดต OTA จะได้เฟิร์มแวร์ปกติที่ไม่มีบลูทูธ AI อ่านค่าสดได้ ("เครื่องร้อนไหม") และพูดเตือนเองเมื่อเครื่องร้อนจัดหรือไดชาร์จไม่ชาร์จ **OBD-II อัจฉริยะ (T112):** หาโปรโตคอลของรถเอง (จำไว้ และลองทีละตัวเมื่อ adapter หาเองไม่เจอ) และหา baud ของ adapter เอง อ่าน**ทุก PID ที่รถมี** โดยอ่านตัวที่จำเป็นก่อน (เร็วตอนเปิดหน้าปัด ช้าลงตอนปิด) **รหัสปัญหาพร้อมความหมาย** (stored / pending / permanent) freeze frame, VIN, readiness และล้างรหัส **วิเคราะห์สุขภาพรถ**จากค่าสด (ความร้อนขึ้นเร็ว ไดชาร์จไม่ชาร์จ แบตอ่อนตอนจอด/ตอนสตาร์ท ส่วนผสมบาง/หนาหรือมีรอยรั่วอากาศ เดินเบาไม่นิ่ง น้ำมันใกล้หมด) และ**ทริปพร้อม กม./ลิตร** (จาก PID อัตราใช้น้ำมัน, MAF หรือ MAP) ใช้ความเร็วจาก GPS มือถือเมื่อกล่องมอเตอร์ไซค์ไม่มี หน้าปัดแบบที่ 4 **"ข้อมูลรถ + วิเคราะห์"** (9 ค่า, รหัสปัญหา, สิ่งผิดปกติที่ร้ายแรงสุด) และไอคอนเครื่องยนต์สีอำพันเมื่อไฟเช็คเครื่องติด ถาม "รถเป็นยังไงบ้าง" "สแกนรถให้หน่อย" "P0420 คืออะไร" (ไม่ต้องมีรถ) หรือ "ล้างรหัสปัญหา" — ตัวจำลองในตัวมีรหัสปัญหาด้วย ลองได้ทั้งหมดโดยไม่มีรถ — ยังไม่ได้ทดสอบกับรถจริง [wiki/16](wiki/16-Vehicle-Dash.md) |

### ทางเลือก A — ใช้เฟิร์มแวร์สำเร็จรูป (ไม่ต้องลงโปรแกรมพัฒนา)

1. ดาวน์โหลด `PersonalAIBot-ESP32-v…-factory.bin` จากหน้า **[Releases](https://github.com/skyliner2008/PersonalAIBot-ESP32/releases)**
   บอร์ดอื่นมีไฟล์ของตัวเอง (ตั้งแต่ release ถัดไป): `-factory-p4.bin` (ESP32-P4), `-factory-xh-s3e-ai.bin` (XH-S3E-AI),
   `-factory-xmini-c3.bin` (Xmini-C3) — อัปเดตผ่าน Wi-Fi ก็หยิบเฉพาะ `-app-….bin` ของบอร์ดตัวเอง
2. เปิด **[espressif.github.io/esptool-js](https://espressif.github.io/esptool-js/)** ด้วย Chrome หรือ Edge เสียบบอร์ดด้วยสาย USB-C แล้วกด **Connect**
   (ถ้าหาบอร์ดไม่เจอ: กด **BOOT** ค้าง → แตะ **RESET** → ปล่อย BOOT แล้วกด Connect ใหม่)
3. ช่อง Flash Address ใส่ **`0x0`** → เลือกไฟล์ `.bin` → **Program** เสร็จแล้วกด **RESET** ที่บอร์ด

ใช้ command line ก็ได้: `esptool.py --chip esp32s3 write_flash 0x0 PersonalAIBot-ESP32-v4.9.4-factory.bin`

**📱 แอปเล็กสำหรับแฟลช (T195):** **`ESP32-AI-Flasher.apk`** จาก release (~0.8 MB ขอสิทธิ์แค่อินเทอร์เน็ต) ทำแค่: ตรวจว่าเสียบบอร์ดรุ่นไหน (4 รุ่น) → โหลดเฟิร์มแวร์ล่าสุดจาก GitHub แฟลชให้ · ตั้งค่า · ดู log (`python tools/build_flasher_apk.py`) — ถ้ามีแอป Flasher 1.0 เดิม ให้ถอนก่อนครั้งเดียว

**📱 แฟลชจากมือถือ Android (ไม่ต้องมีคอม):** ติดตั้งแอปมือถือ **Personal AI Bot** (`PersonalAIBot-Mobile.apk` — ไม่อยู่ใน release ตั้งแต่ v4.9.6 (T196, ~225 MB) ให้ build เอง:
`python tools/build_mobile_apk.py`) แตะไอคอนชิปที่แถบบนเพื่อเปิดหน้า **บอร์ด ESP32** เสียบสาย USB-C จากมือถือเข้าบอร์ด (มือถือต้องรองรับ USB OTG) แล้วกด **แฟลชลงบอร์ด**
แอปดาวน์โหลด release ล่าสุดเองและตรวจ sha256 (และลายเซ็นของ release) · **อัปเดต** เขียนไฟล์ `-app.bin` โดยค่าที่ตั้งไว้และความจำอยู่ครบ ·
**ติดตั้งใหม่ทั้งหมด** เขียนไฟล์ factory · เลือกไฟล์ `.bin` ในเครื่องก็ได้ · ใช้ได้เฉพาะ Android 8 ขึ้นไป (iOS ไม่ให้แอปใช้ USB serial)
แอปเดียวกันนี้ใช้เป็น **ESP32-AI Studio ฉบับพกพา** ผ่านสายเส้นเดิมได้ด้วย: ดูสถานะ + ปุ่มด่วน (ไมค์ / พัก / ปลุก / ต่อ AI ใหม่ / บทสนทนาใหม่ / รีบูต),
พิมพ์แชทกับผู้ช่วย, log สด (กรอง, แชร์, พิมพ์คำสั่ง console) และตั้งค่า (สแกน Wi-Fi, API key + ทดสอบ, โปรไฟล์, เสียง, โมเดล, ความดัง, ความสว่าง ...) — ดู [wiki 17](wiki/17-Mobile-Flasher.md)
แอป**อัปเดตตัวเองได้**จากหน้า release: ตั้งค่า → **อัปเดตแอป** (ตรวจเองวันละครั้ง ตรวจ sha256 แล้ว Android ถามก่อนติดตั้ง ข้อมูลในแอปอยู่ครบ) — ใช้ได้กับ release ที่มี `PersonalAIBot-Mobile.json` (ตั้งแต่ v4.4.2)

> ไฟล์ factory เริ่มที่ `0x0` จึง**ล้างค่าตั้งค่าเดิมในบอร์ด**ไปด้วย (ติดตั้งใหม่สะอาด)
>
> **บอร์ดเป็น v3.5.0 ขึ้นไปแล้ว?** อัปเดตผ่าน Wi-Fi ได้เลย: เมนูตั้งค่า → **อัปเดตเฟิร์มแวร์** บอร์ดดาวน์โหลดไฟล์ `-app.bin` ของ release ล่าสุด ตรวจ (sha256, header, เวอร์ชัน และลายเซ็นของ release เมื่อตั้งกุญแจแล้ว) แล้วติดตั้ง โดย**ค่าที่ตั้งไว้และความจำอยู่ครบ** ถ้าเวอร์ชันใหม่เปิดไม่ผ่านจะกลับเป็นเวอร์ชันเดิมเอง · เช็คอัปเดตได้แม้เปิดวิทยุหรือ AI กำลังพูด (T121: handshake TLS กับ GitHub รันที่ priority สูงขึ้น — เดิมช้าจน GitHub ตัด ขึ้น "ติดต่อ GitHub ไม่ได้ (HTTP -1)") — ดู [wiki 13](wiki/13-OTA-Update.md)

### บูตครั้งแรก — ใส่ Wi-Fi และ API key ของคุณเอง

1. **ปรับแต่งทัช** — แตะเป้า 3 จุด
2. แตะ ⚙ (หรือกด **BOOT** ค้าง 1.5 วิ) → **Wi-Fi** → สแกนแล้วเลือกเครือข่าย → พิมพ์รหัสด้วยคีย์บอร์ดไทย/อังกฤษบนจอ
3. **API key** → พิมพ์ key → **ทดสอบ API key** จะบอกว่า key ใช้โมเดลไหนได้บ้าง
4. เมื่อจอขึ้น **"พร้อมคุย"** — พูดได้เลย

**หรือตั้งค่าจากคอมพิวเตอร์ผ่านการ์ด SD:** คัดลอก [`tools/sd_card/ai-setup.txt`](tools/sd_card/ai-setup.txt) ไปไว้ที่หน้าแรกของการ์ด
micro SD (FAT32) กรอก `WIFI_SSID`, `WIFI_PASSWORD`, `GEMINI_API_KEY` แล้วเสียบการ์ดเข้าบอร์ดและเปิดเครื่อง
บอร์ดจะอ่านไฟล์ เก็บค่าแบบเข้ารหัสใน `agent/secrets.json` บนการ์ด แล้วลบไฟล์ข้อความธรรมดาทิ้ง
(ปุ่ม **💾 ไฟล์สำหรับการ์ด SD...** ใน Studio สร้างไฟล์นี้ให้ได้)

ไม่อยากพิมพ์บนจอเล็ก? ใช้แอป PC (หัวข้อถัดไป) ตั้งค่าได้ทุกอย่าง

## 🔒 ความปลอดภัย & ความเป็นส่วนตัว

**รหัส Wi-Fi และ API key เก็บอยู่ที่ไหน**

| ที่ | มีความลับไหม |
|---|---|
| ซอร์สโค้ดใน repo นี้ | **ไม่มี** — ความลับพิมพ์ใส่บนเครื่อง (เมนูทัชหรือ Studio) ไม่ได้อยู่ในโค้ด |
| `include/secrets.h` (ค่าเริ่มต้นตอน build, ไม่บังคับ) | มีเฉพาะถ้าคุณกรอกเอง — ไฟล์นี้ถูก **git-ignore** จึงไม่ถูกอัปโหลด ส่วน `secrets.example.h` มีแค่ค่าตัวอย่าง |
| ไฟล์เฟิร์มแวร์ที่ build แล้ว (`.pio/`) | มีเฉพาะถ้าใช้ `secrets.h` — โฟลเดอร์ build ถูก git-ignore |
| การ์ด SD — `agent/secrets.json` (ถ้าไม่ได้ใส่การ์ด: NVS ในแฟลชบอร์ด) | **มี แต่เข้ารหัส** AES-256-GCM ด้วยกุญแจที่คำนวณจาก MAC + eFuse unique ID ของชิปตัวนั้น (`src/app/SecretBox.*`) — ไฟล์เปิดได้เฉพาะบอร์ดที่สร้าง (ย้ายการ์ดไปบอร์ดอื่น = ตั้งค่าใหม่ด้วย `ai-setup.txt`) เปิดการ์ดบนคอมพิวเตอร์จะไม่เห็นรหัส และ `ai-setup.txt` ถูกเขียนทับแล้วลบทันทีหลังอ่าน สำเนาแบบข้อความธรรมดาเดิมถูกล้างอัตโนมัติครั้งเดียว (รวมสำเนาที่ไดรเวอร์ Wi-Fi เก็บเอง ซึ่งปิดแล้วด้วย `WiFi.persistent(false)`) |

- ไม่ใช่ flash encryption เต็มรูปแบบ: คนที่ได้ทั้งบอร์ด**และ**เฟิร์มแวร์นี้ไปยังคำนวณกุญแจได้ ควรใช้ API key แยกเฉพาะบอร์ดนี้ และเปลี่ยน key ถ้าบอร์ดหาย
- เฟิร์มแวร์และ Studio **ไม่เคยพิมพ์** API key หรือรหัส Wi-Fi ออกมา — `config` แสดงแค่ตัวย่อที่ซ่อนแล้วและ `secretsSealed` ไฟล์ตั้งค่าที่ส่งออกไม่มีความลับ ไฟล์เสียงที่อัด (`recordings/`) ถูก git-ignore
- ขณะเปิดไมค์ เสียงจะถูกส่งไปที่ Gemini API ของ Google ส่วนความจำและโน้ตอยู่ใน SD/แฟลชของบอร์ด
- Gemini API key ส่งใน header `x-goog-api-key` (ไม่อยู่ใน URL) และ tools ข้อมูลใช้เฉพาะ HTTPS ที่ตรวจใบรับรอง — `http://` ธรรมดาถูกปฏิเสธ

## 🧑‍💻 สำหรับนักพัฒนา

- **Fork & build:** `pio run` build ได้จาก clone ใหม่โดยไม่ต้องมี `secrets.h` — ค่าตั้งค่าอยู่ใน NVS (`src/app/Settings.*`) key ของคุณจึงไม่เข้าไปอยู่ในซอร์สโค้ด
- **เพิ่ม tool:** ประกาศใน `AgentTools::addDeclarations` (`src/agent/AgentTools.cpp`) tool ที่ใช้เน็ตใส่ใน `src/agent/WebToolsExtra.cpp` และวาด `CardData` (ดู [wiki/11](wiki/11-Data-Tools-and-Cards.md))
- **ทดสอบไม่ต้องมีบอร์ด:** `host_tests\run_tests.bat` — บนบอร์ดเรียก tool ทุกตัวได้จากแท็บ 🧰 ใน Studio หรือ serial (`tool <name> {json}`)
- **ดูบทสนทนากับ Live API:** พิมพ์ `trace on` ใน serial → ขึ้นบรรทัด `[Trace]` ทุกข้อความจากเซิร์ฟเวอร์ (transcript, การเรียก tool, `generationComplete` / `turnComplete` — ก้อนเสียงแค่นับจำนวน) และทุกข้อความ JSON ที่บอร์ดส่ง (`trace off` ปิด, ไม่บันทึกค่า) — ใช้หาสาเหตุ AI ตอบซ้ำ 2 รอบหลังเรียก tool ([T071](wiki/07-Troubleshooting-Log.md))
- **ออก Release:** แก้ `FIRMWARE_VERSION` ใน `src/app/AppConfig.h` และ `firmware-p4/src/app/AppConfig.h` (เลขเดียวกัน: release เดียวมีไฟล์ทั้งสองบอร์ด T155) → commit → `git push` → `python tools/publish_release.py` สคริปต์จะ build ไฟล์ factory (`tools/make_release.py`) สร้าง Release แบบร่าง แนบไฟล์ factory และไฟล์ OTA `-app.bin` (พร้อม `.sha256`) และแอปมือถือ `PersonalAIBot-Mobile.apk` (build ให้อัตโนมัติเมื่อเครื่องมี Android SDK ไม่ต้องสร้าง keystore — เซ็นด้วย debug key ของ SDK เว้นแต่สร้าง keystore เองด้วย `--create-keystore`) เผยแพร่ แล้วดาวน์โหลดกลับมาเทียบ sha256 โดยรัน host tests ก่อนเผยแพร่เสมอ (`--skip-tests` ใช้เฉพาะเครื่องที่ไม่มี compiler) — Release ของ repo นี้เป็นแบบ **immutable** เผยแพร่แล้วแก้ไฟล์หรือใช้ชื่อ tag ซ้ำไม่ได้ ทุกครั้งต้องใช้เลขเวอร์ชันใหม่ (`--dry-run` = ตรวจอย่างเดียว) รหัส Wi-Fi และ API key ไม่ต้องใช้กุญแจ release เลย: เก็บใน SD card ของบอร์ดแบบเข้ารหัสด้วยกุญแจที่คำนวณจากชิปของบอร์ดนั้น (เปลี่ยนการ์ดหรือเปลี่ยนบอร์ด = ตั้งใหม่) และอัปเดต OTA แล้วยังอยู่ครบ **ทางเลือก — เซ็นอัปเดต OTA:** ESP32-AI Studio แท็บ 🔧 เฟิร์มแวร์ → **🔑 สร้างกุญแจ** (หรือ `pip install cryptography` → `python tools/ota_keygen.py`) → commit `src/app/OtaPublicKey.h` และสำรองกุญแจส่วนตัวที่สคริปต์บอกที่อยู่ไว้ (อยู่นอก repo) — บอร์ดที่ build พร้อมกุญแจนั้นจะติดตั้งเฉพาะอัปเดตที่เซ็นด้วยกุญแจนี้ ([wiki 13](wiki/13-OTA-Update.md))
- **CI:** [`.github/workflows/firmware.yml`](.github/workflows/firmware.yml) ทำแบบเดียวกันบน GitHub Actions แต่ตอนนี้ตั้งเป็นกดรันเองเท่านั้น (*Actions → Firmware → Run workflow*) และ job ออก release จะรอ job host-tests ผ่านก่อน — `tools/make_release.py` ไม่ยอมทำงานถ้า `include/secrets.h` มีค่าจริง และสแกนไฟล์หาสิ่งที่หน้าตาเหมือน API key
- **เอกสาร:** โฟลเดอร์ `wiki/` เป็น Obsidian vault — ปัญหาที่แก้ได้ช่วยบันทึกใน [wiki/07-Troubleshooting-Log.md](wiki/07-Troubleshooting-Log.md)
